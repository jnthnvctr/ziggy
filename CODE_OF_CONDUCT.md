# Code of Conduct

Ziggy is built for kids, by people who care about them. We follow the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, welcome newcomers, and keep discussion about the work.
Harassment of any kind isn't tolerated.

Report concerns privately to the maintainer via GitHub (open a private security advisory or
message @jnthnvctr). Reports are handled confidentially.
